# YouTube公開時期ソートゲーム

## プロジェクト概要

vite + GitHub Pages で作る、YouTube動画のサムネイルを公開順に並べるゲームを作成する。

### 仕様
- 動画情報・サムネイルはスクリプトで取得し、リポジトリに保存する
- スクリプトでは Youtube Data APIを使用する
- ゲームはドラッグ＆ドロップでサムネイルを並び替え、正解・不正解の判定を行う
- 難易度に応じて最大件数を5,10にする
- 結果画面では動画情報（タイトル、公開日、URL）を表示する
- スマホ対応も行う
- デザインはシンプルだが、演出はふんだんに盛り込む
